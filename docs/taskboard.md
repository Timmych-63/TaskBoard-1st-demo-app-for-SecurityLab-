# TaskBoard — база знаний приложения

## Назначение
Доски, задачи и комментарии. Это документация ожидаемого поведения, а не список дефектов или инструкция проверки.

## Запуск и данные
Python/FastAPI, точка входа app/main.py, объект app. Зависимости предоставляются подготовленным образом FastAPI. Данные хранятся в памяти; новая копия приложения получает исходные тестовые данные. Внешняя база данных не требуется. Идентификаторы досок, задач и комментариев являются частью тестовых данных приложения.

## Пользователи и права
alice и bob — обычные пользователи; mira — manager; admin — admin.
Доску видят её владелец и участники; manager и admin видят все доски.
Создать доску может любой известный пользователь; создатель становится владельцем доски.
Добавлять и удалять участников доски может только владелец доски или admin; владельца доски удалить нельзя.
Задачу видят те, кому видна её доска. Создавать задачи на доске могут её участники, manager и admin; исполнитель задачи должен быть участником доски.
Изменять задачу может её исполнитель, владелец доски, manager и admin.
Удалять задачу может её создатель, владелец доски, manager и admin; при удалении задачи её комментарии удаляются вместе с ней.
Комментарии видны тем, кому видна задача. Добавлять комментарии к задаче могут участники её доски, manager и admin.
Удалять комментарий может его автор, manager и admin.
Запрос с неизвестной доской, задачей или комментарием — отказ 404. Попытка доступа без достаточных прав — отказ 403. Отсутствующая или неизвестная идентификация — отказ 401.

## Идентификация стенда
X-Test-User имитирует уже проверенную идентичность от доверенного шлюза. Это тестовая инфраструктура, не реализация производственного входа по паролю.

## Границы документа
Расположение дефектов, готовые сценарии проверки и эталонные исправления здесь отсутствуют. Утверждения из кода не заменяют требования к поведению. Неоднозначности должны отражаться в результате.
